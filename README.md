# Telegram для Meta Ray-Ban Display — экспериментальный прототип

Бесплатное приложение с прямым подключением к Telegram через MTProto/WebSocket.
Не связано с Telegram, Meta или Ray-Ban. Совместимость с очками и реальный вход
в аккаунт пока не проверены. Сервер приложения не нужен. Telegram API бесплатен.

## 1. Опубликовать

Создай отдельный публичный репозиторий `rayban-telegram` в GitHub.
Загрузи содержимое этой папки: `index.html`, README, лицензии и папку `source`.
В Settings → Pages выбери Deploy from a branch → main → / (root) → Save.
После завершения публикации открой на телефоне:

https://gagulvardanyan92-tech.github.io/rayban-telegram/

Это будущий адрес после публикации; автоматически он не создан.
Первый вход делай по HTTPS-адресу, не через локальный файл.

## 2. Получить API ID и API Hash

На телефоне или компьютере открой https://my.telegram.org и войди по своему номеру.
Открой API development tools. Если приложение ещё не создано:

- App title: `Glasses Chat`
- Short name: `glasseschat`
- Platform: `Web` (или `Other`, если Web недоступен)
- URL: HTTPS-адрес твоего опубликованного приложения
- Description: `Personal chat client for my display glasses`

Нажми Create application. Скопируй API ID и API Hash в поля опубликованного
приложения на телефоне. Не вставляй их в файлы проекта и не отправляй в чат.
Если приложение уже создано, используй существующие ключи.

Документация: https://core.telegram.org/api/obtaining_api_id

## 3. Войти на телефоне

Введи ключи и телефон с кодом страны, нажми «Войти в Telegram».
Введи код из официального Telegram и облачный пароль, если он включён.
Приложение не отправляет сообщения автоматически. Просмотр чата не помечает
его прочитанным. Сообщения отправляются только кнопкой «Отправить».

## 4. Перенести вход в очки

Открой «Настройки» в приложении. Задай отдельный пароль от 8 символов.
Создай и скопируй ссылку. В Meta AI добавь её через Web Apps, как YouTube.
В очках введи пароль переноса. Поле использует системный ввод очков.
Ссылка для первого переноса действует 24 часа. Можно создать новую.
При желании отметь «Сохранить вход в очках».

Пароль должен быть достаточно длинным: шифрование не защищает слабый пароль
от перебора, если кто-то получил ссылку. Ссылка содержит зашифрованную сессию
и ключи (AES-GCM, PBKDF2-SHA256, 250 000 итераций). Фрагмент после `#` не
отправляется GitHub Pages в HTTP-запросе, но виден приложению Meta AI,
буферу обмена и браузеру, поэтому не публикуй и не пересылай ссылку посторонним.
Не добавляй её в README, исходный код или публичные задачи GitHub.

Если Meta AI не сохраняет часть адреса после `#`, этот способ переноса
на данном устройстве не заработает: понадобится другой способ подключения.

## Что работает в первой версии

- Список до 60 последних облачных чатов, фильтр по имени.
- Последние 30 сообщений, кнопка загрузки предыдущих.
- Текстовый ответ с подтверждением отправки.
- Сохранение черновика в памяти страницы до успешной отправки.
- Обновление открытого чата каждые 12 секунд, пока страница видна.
- Демо с вымышленными чатами без подключения аккаунта.
- Управление кнопками, Tab, стрелками и Enter; Escape возвращает к списку.

Голосовой ввод предоставляет система очков. Приложение не имеет собственного
распознавания речи и не записывает микрофон. На ПК вводится обычный текст.
Если системная диктовка не передаёт текст в поле, нужно будет адаптировать
обработку событий после проверки на устройстве.

## Ограничения

Нет секретных чатов, звонков, проигрывания видео/голосовых, фото, стикеров,
глобального поиска и отправки вложений. Вместо вложений показаны подписи.
В группах имя автора пока заменено на «Участник». Каналы могут быть только
для чтения. Sponsored messages каналов пока не реализованы, поэтому это
личный экспериментальный прототип, не готовый публичный Telegram-клиент.
Нельзя гарантировать доступность WebSocket в браузере очков; это нужно
проверить на реальном устройстве. Большая библиотека может загружаться медленно.

## Хранение и выход

Без флажка «Сохранить вход» сессия держится в памяти страницы.
При включении флажка API-ключи и сессия записываются в localStorage браузера
без дополнительного шифрования; это доступ к аккаунту, поэтому используй
только своё устройство. Переписка не записывается приложением в localStorage.
Для полного отзыва доступа открой официальный Telegram → Настройки → Устройства
и заверши сессию Display Web App. Встроенная кнопка «Завершить сессию»
тоже отзывает сессию, включая её копию на очках/телефоне.

## Исходники и сборка

В папке `source` — исходники и зафиксированные зависимости.
Node.js 22+:

```powershell
cd source
npm ci --ignore-scripts --omit=optional
npx webpack --config webpack.config.cjs
```

Для сборки одного HTML помести `source` в `work/telegram-build` относительно
рабочей папки и запусти `node package-deliverable.cjs`; результат появится
в `outputs/rayban-telegram`. Файл `index.html` содержит библиотеку внутри,
не загружает JavaScript со сторонних CDN.

Используется архивная GramJS 2.26.22 для прототипа. Перед публичным выпуском
нужна миграция на поддерживаемую библиотеку, проверка безопасности и выполнения
Telegram API Terms. Это не проверенный для публичной эксплуатации продукт.
