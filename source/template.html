Чаты в очках

Telegram · экспериментальная версия 1

Первый вход сделай на телефоне. Затем перенеси вход в очки через ссылку с паролем.

Неофициальный клиент. Соединение с Telegram идёт прямо из браузера. Коды входа и переписки не отправляются нашему серверу: сервера у приложения нет.

Получить ключи: my.telegram.org → API development tools. Не публикуй ключи и ссылку переноса.

Выбери чат. В очках поле ввода использует системную диктовку.

Перенос в очки

Задай пароль, создай ссылку и добавь её в Web Apps через Meta AI. В очках введи этот пароль.

В ней зашифрован вход в твой аккаунт. Не загружай ссылку на GitHub. На телефоне и в очках используется одна сессия; её можно завершить через Telegram → Настройки → Устройства.

Сохранённый вход доступен браузеру на этом устройстве. Используй только своё устройство.

Подключить Telegram

Введи пароль, который ты задал на телефоне при создании ссылки.
